# 01 Product Requirements Document (PRD)

## 1. Vision & Core Objective
PANDAV AI is a production-grade, self-hosted, highly autonomous AI engineering and automation platform. It functions as a **ONE-PROMPT AUTONOMOUS ENGINEERING SYSTEM**: given a single high-level objective, it independently plans, researches, codes, builds, tests, security-audits, deploys, monitors, and recovers software systems without routine micromanagement.

## 2. Key Target KPI
- **Autonomous Task Completion Rate**: Target 99.998% for eligible, authorized, reversible/routine engineering tasks.
- Continuously measured and recorded as an empirical engineering metric.

## 3. User Workspaces
1. **Helper Chat**: Safe conversational assistance, architecture guidance, troubleshooting without direct arbitrary code execution.
2. **Doctor Sandbox**: Fully isolated container workspace with non-root security contexts, build runner, test runner, snapshots, and rollback.
3. **Engineer Security Sandbox**: Authorized defensive validation, SAST, DAST, secret scanning, dependency checking, and verification.
