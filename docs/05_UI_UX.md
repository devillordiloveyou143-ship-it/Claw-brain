# 05 UI/UX Design

The web interface is built with responsive Tailwind CSS:
1. **One-Prompt Mission Dashboard**: Single input bar that visualizes real-time dynamic task graphs, KPI metrics, and cluster endpoints.
2. **Doctor Sandbox View**: Interactive file tree, syntax-highlighted code editor, test execution controls, and container execution logs.
3. **Engineer Security View**: Target authorization badge, vulnerability findings table with severity indicators and remediation notes.
4. **Helper Chat View**: Conversational dialogue with markdown support.
5. **Policy & Audit View**: Immutable audit ledger and human approval boundary cards.
